Data sources — harvest from PubMed

Search PubMed for recent higher-quality evidence (reviews · meta-analyses · RCTs in older adults) on a topic and extract claims grounded in each abstract. New claims are written unverified and go to the review queue — the source is a real PMID by construction.

Tick guidelines only to discover practice guidelines PubMed indexes on that topic (WHO / USPSTF / society guidelines), with a real PMID by construction — no need to know a specific document.

— one click sweeps a curated list of well-known geriatrics guidelines via PubMed; runs in batches.

Data sources — harvest a clinical guideline

Extract recommendation claims from a practice guideline (WHO · CDC · Canadian geriatric societies · etc.). Give it a URL to fetch — a PDF or HTML page (article text is extracted, boilerplate dropped) — or paste the text, plus a source (a DOI, or the URL). Each claim is grounded in a verbatim quote, written unverified, and goes to the review queue; the source is the guideline's DOI/URL.

Maintenance

Attach standard vocabulary codes (MONDO · HP · GO · ChEBI · FoodOn · MeSH · RxNorm · ROR · ORCID) to nodes by resolving their names against the authorities — only accepted on a verified name match. Runs in batches; safe to re-run.
